# Пединбург — карты заклинаний

Веб-приложение для каталога, печати и редактирования карточек заклинаний D&D 5e
в оформлении из Figma: карточка 180 × 252 pt (63,5 × 88,9 мм), 9 карточек на листе A4.

![Каталог](ref/catalog-final.png)

## Что умеет

**Каталог (`/`)**
- 388 заклинаний из Google Таблицы: 10 кругов, 8 школ, поиск по названию/школе/компонентам.
- Фильтры по кругу и школам, сортировка, «только адаптированные».
- Кнопка «+» кладёт карточку в набор и **не уводит со страницы**; счётчик в шапке и плашка внизу.
- Карточка открывается в диалоге с полным текстом и кнопкой «Своя версия».

**Карточка**
- Точная геометрия из Figma: обводка 1 pt, белая кромка 2 pt, шапка #B9F3B7, поля 12/8/6 pt.
- Текст раскладывается собственным движком: автоподбор кегля 9 → 6,1 pt, переносы, жирные лейблы
  («Спасбросок:», «На высоких уровнях:»), обрезка с многоточием, если текст не помещается.
- Иллюстрация: загруженная, по ссылке (Google Диск) или сгенерированная арканная заглушка.

**Печать (`/print`)**
- Отдельная страница: листы A4 3 × 3, превью каждого листа, порядок карточек (выше/ниже), удаление.
- Настройки: линии реза, номера листов.
- Экспорт PDF на pdf-lib: векторный текст, встроенные Alegreya Sans, картинки, точные размеры.
  Файл готов к печати без полей.

**Мои карточки (`/library`) и редактор (`/editor`)**
- Создание своих карточек: название, круг, школа, ритуал, накладывание/дистанция/длительность,
  компоненты, художественное описание, механика, улучшение.
- Оформление: 5 пресетов и свои цвета шапки/акцента/бумаги/текста, включение/выключение блоков.
- Иллюстрация: файл (сжимается до 720 px) или ссылка.
- Пресеты хранятся в браузере; экспорт/импорт JSON для переноса.
- PDF одной карточки прямо из редактора.

**Иллюстрации из Google Диска**
- На странице «Мои карточки» вставьте ссылку на папку — файлы сопоставятся с заклинаниями
  по имени («Огненный шар.jpg» → «Огненный шар»), jpg/png/webp.
- Публичная папка читается без ключа; для больших/закрытых папок задайте `GOOGLE_API_KEY`.

## Запуск

```bash
npm install
npm run dev
```

Откройте http://localhost:3000

Если установка падает с `EPERM` (npm-кэш вне рабочей папки):

```bash
npm install --cache .npm-cache
```

## Данные

Источник — Google Таблица с листами «0 круг» … «9 круг», чтение через `gviz` CSV.
ID задаётся переменной `SPELL_SHEET_ID` (см. `.env.example`); таблица должна быть открыта по ссылке.

- `/api/spells` — читает 10 листов, нормализует и кэширует на 10 минут.
- При недоступности таблицы отдаёт снапшот `data/spells.json` (обновляется при каждом успешном чтении).
- Ссылки на иллюстрации проходят через `/api/image` (прокси Drive), список файлов папки — `/api/drive`.

## Структура

```
src/
  app/
    page.tsx              каталог (SSR из снапшота + клиентские фильтры)
    print/page.tsx        листы A4 и экспорт PDF
    editor/page.tsx       редактор карточки
    library/page.tsx      мои карточки, импорт/экспорт, Google Диск
    api/spells|image|drive
  components/
    card/                 SpellCard 180×252 pt, ScaledCard/FixedCard
    catalog/              плитка, диалог, плашка набора
    print/                превью листа A4
    ui/                   Button, Chip, Badge, Switch
  lib/
    card-spec.ts          геометрия карточки и листа
    layout.ts             переносы, автоподбор кегля, обрезка
    card-layout.ts        раскладка всех блоков карточки (кэш)
    measure.ts            измерение текста (canvas), загрузка шрифтов
    pdf.ts                сборка PDF на pdf-lib
    normalize.ts          Google Таблица → Spell
    text.ts               футы→метры, «Кон. до 1 м.», падежи, лейблы
    art.ts                генератор заглушек
    client-store.ts       selection/custom/drive в localStorage
tools/
  shot.mjs                скриншоты через CDP
  pdf-flow.mjs            сквозной тест печати → PDF
  render-pdf.mjs          PDF → PNG (pdfjs)
```

## Проверка

- `npx tsc --noEmit` — без ошибок.
- Сквозной тест: `/print` → «Скачать PDF» → `ref/downloads/*.pdf` (11 карточек, 2 листа).
- Пример: `samples/pedinburgh-spells-sample.pdf`.

## Ограничение окружения DSH

Next.js порождает дочерний серверный процесс, а песочница `workspace-write` блокирует `spawn`
(EPERM). Для `next dev` / сборки и для скриншотов Chromium внутри DSH нужно разовое разрешение
`danger-full-access`. В обычном терминале ограничения нет.
